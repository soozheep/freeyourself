## Assets

Upload the following from Google Drive "07 Free Yourself" folder into the `assets/` directory:

- `fy-cover.jpg` → assets/fy-cover.jpg
- `07_Free Yourself.mp3` → assets/07_Free Yourself.mp3
- Lyric cards `fy-01.png` … `fy-08.png` → assets/lyrics/
- Teaching cards `fy-card-01.png` … `fy-card-04.png` → assets/cards/

Then connect the repo to Vercel and deploy.
